# 🛒 EShop - E-Commerce Management System

An enterprise-style E-Commerce Management System built with **ASP.NET Core**.

The project demonstrates a layered architecture for building maintainable and scalable web applications using ASP.NET Core MVC, Web API, Entity Framework Core, and ASP.NET Core Identity.

# 📂 Solution Structure

```
EShop.Common
│
├── Shared utilities
├── Extensions
├── Validation Attributes
└── Security Helpers

EShop.Entities
│
├── Domain Entities
├── Identity Models
└── Base Entities

EShop.DataLayer
│
├── DbContext
├── Entity Configurations
├── Repositories
├── Unit of Work
└── EF Core Migrations

EShop.Services
│
├── Business Logic
├── Identity Services
├── Product Services
├── Category Services
├── Cart Services
└── Email Services

EShop.ViewModels
│
├── DTOs
├── Request Models
└── View Models

EShop.Web
│
├── ASP.NET Core MVC
├── Controllers
├── Razor Views
└── Authentication

Ticket.WebApi
│
└── RESTful API
```

│

│
├── Services
